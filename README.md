Mantive o mesmo código da versão em JavaScript/Node.JS de propósito: o objetivo aqui não era treinar lógica nem sintaxe, e sim testar a geração de um executável `.exe` com o Nexe.

Para gerar o `.exe` com essa ferramenta você vai precisar de:

- Nexe instalado globalmente (`npm install -g nexe`). Ele não entra na lista de dependências do pacote, apenas como comentário do manifesto;
- Visual Studio Community, instalado com todas as opções — não sei dizer quais são estritamente necessárias;
- Nasm.

O arquivo `.exe` foi gerado no Windows.

A documentação oficial do Node lista os requisitos de compilação na plataforma da Microsoft.

A primeira compilação demora bastante.
